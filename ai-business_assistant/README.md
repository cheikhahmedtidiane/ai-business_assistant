# AI Business Assistant

**AI Business Assistant** est un projet d'automatisation et d'assistance textuelle basé sur l'intelligence artificielle. Cet atelier pratique met en œuvre des techniques avancées de **Prompt Engineering** pour traiter, analyser et structurer des flux d'informations internes et opérationnels (emails, communiqués, logs serveurs).

## Structure du Projet

Le dépôt est composé des fichiers essentiels suivants :
* **`atelier_prompt_ai-business_assistant.ipynb`** : Le notebook Jupyter principal contenant les cas pratiques, le code d'appel aux LLM et l'évaluation des prompts.
* **`communique_interne.xml`** : Source de données contenant les notes et annonces officielles de l'organisation à analyser.
* **`email_entrant_bonus.xml`** : Flux de courriels clients ou partenaires à qualifier et traiter automatiquement.
* **`serveur_central_dk.xml`** : Fichier de logs ou de données d'infrastructure pour l'analyse technique orientée business.

## Technologies Utilisées

* **Langage :** Python (Jupyter Notebook)
* **Format de données :** XML (Données d'entrée), Markdown / JSON (Sorties structurées)
* **Concepts clés :** Ingénierie de prompt, structuration des sorties, gestion du contexte.

##  Prise en main

1. **Cloner le projet :**
   ```bash
   git clone https://github.com
   cd ai-business_assistant
   ```
2. **Lancer l'atelier :**
   Ouvrez le notebook `atelier_prompt_ai-business_assistant.ipynb` dans votre environnement Jupyter ou Google Colab préféré pour exécuter les cellules et tester les prompts.
